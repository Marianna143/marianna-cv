# РентТрекер — аналитика рынка недвижимости

Личный продукт, 2025–2026.

## Проблема

Данные об объектах недвижимости приходят из разных источников и выгрузок, отличаются по структуре и неудобны для сравнения. Из-за этого сложнее отслеживать цены, параметры объектов и изменения рынка.

## Что сделано

- объединены данные из API и табличных выгрузок;
- приведены к единой структуре ключевые поля объектов;
- автоматизированы сбор и подготовка данных;
- сформированы показатели для сравнения цен, параметров и динамики;
- подготовлена основа для регулярного анализа и принятия решений.

## Что показывает проект

Умение работать с неоднородными источниками, уточнять требования к данным, проектировать структуру показателей и связывать техническую интеграцию с бизнес-задачей.

Исходные данные и рабочая версия продукта не публикуются, поскольку могут содержать закрытую или производственную информацию.
