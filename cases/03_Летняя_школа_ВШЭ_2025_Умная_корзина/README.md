# «Умная корзина» — Летняя школа ФКН НИУ ВШЭ, 2025

## Результат

3-е место из 30 команд в Летней школе по программной инженерии ФКН НИУ ВШЭ.

## Задача

Спроектировать бизнес-приложение на платформе 1С, которое помогает пользователю подобрать продуктовую корзину с учетом целей питания и автоматически рассчитывает КБЖУ.

## Моя работа

- моделирование бизнес-процессов;
- описание функциональных требований;
- проработка пользовательских сценариев;
- логика автоподсчета КБЖУ и формирования продуктовых наборов;
- проработка интеграции каталога через API Яндекс Еды;
- командная презентация результата.
